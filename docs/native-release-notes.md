8.4.1 修复 Windows 和 macOS 长时间运行后的界面卡顿，可直接覆盖升级。

## 安装

每条命令请整行复制。命令安装 8.4.1，当前发布的安装包也可以直接下载。

### macOS（13 及以上，Apple 芯片与 Intel 通用）

在终端运行：

```bash
(p=$(/usr/bin/mktemp) && trap '/bin/rm -f "$p"' EXIT && /usr/bin/curl -q -fsSL --retry 3 -o "$p" https://github.com/yuuuki-creation/po0-clash/releases/download/native-v8.4.1/install.sh && /bin/bash "$p" 8.4.1)
```

脚本会退出并替换已安装的 po0-clash（包括 Flutter 版），装到「应用程序」后启动。应用没有经过苹果公证，脚本会去掉下载带来的隔离标记。
第一次切到「虚拟网卡」时需要输入一次管理员密码，用来安装以 root 运行的内核；取消则继续使用系统代理。

### Windows（10 / 11，x64）

在 PowerShell 里运行：

```powershell
$p = Join-Path $env:TEMP "po0-clash-$(New-Guid).ps1"; try { Invoke-WebRequest -UseBasicParsing -ErrorAction Stop -Uri https://github.com/yuuuki-creation/po0-clash/releases/download/native-v8.4.1/install.ps1 -OutFile $p; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -Version 8.4.1; if ($LASTEXITCODE) { throw "Installer exited with code $LASTEXITCODE." } } catch { throw } finally { Remove-Item -LiteralPath $p -Force -ErrorAction SilentlyContinue }
```

脚本会下载安装程序、校验 SHA-256、请求一次管理员权限，装好后打开应用。这样下载的文件没有网络来源标记，不会触发 SmartScreen 提示。

也可以下载 `po0-clash-8.4.1-windows-x64-setup.exe` 手动运行。安装程序没有签名，SmartScreen 拦下时点「更多信息」→「仍要运行」。

**智能应用控制：** 这个功能开着时，未受信任签名的应用可能仍被拦截，命令安装也不一定能绕开，微软也不提供单个应用的例外。被拦时要在「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置」里关闭它。

应用以管理员身份运行（虚拟网卡需要）。已装 Flutter 版时会先静默卸载它，订阅和加白条目保留并导入。

### Android（8.0 及以上）

按手机的处理器选 APK：绝大多数手机用 `arm64-v8a`，较老的 32 位手机用 `armeabi-v7a`，模拟器用 `x86_64`。

可以直接覆盖安装 Flutter 版，订阅和加白条目会自动导入。覆盖之后不能直接装回 Flutter 版，要先卸载，应用数据会一起清除。

## 桌面性能

- Windows 和 macOS 只在窗口可见时轮询界面数据，上一轮完成后才发下一轮请求。首页只读取流量、连接数量和总量，打开连接页才读取明细。
- 流量图复用画布缓冲区。macOS 菜单栏速率单独更新，模式与接管方式改用 AppKit 分段控件，减轻 SwiftUI 布局负担。

## 功能

- 桌面端：首页（订阅、当前节点、网络接管与连接开关、出站模式、流量、加白、出口 IP）、代理（可展开的策略组和节点网格，排序、
  定位当前节点、单节点与整组测速）、订阅（订阅链接、文件、分享链接导入，覆写、预览、导出、拖动排序）、连接（活动与已关闭）、
  规则（含代理集与规则集）、日志、加白、设置。
- Android：纵向仪表盘卡片和启动按钮、代理、配置、加白、工具。
- 三端都能检查更新：启动时自动检查（可关闭），也可以在设置 / 关于里手动检查。
- 界面有简体中文、English、日本語、Русский。启动中崩溃后下次不自动连接，连续两次会取消选中当前配置。
- 平台各自的：macOS 的菜单栏面板；桌面端的全局快捷键；Windows 的托盘、开机自启、UWP 回环豁免；Android 的分应用代理、按需连接（排除的 Wi-Fi）、
  快捷设置磁贴、外部启停 intent 和 TV 入口。
- po0 与 ggy 自动加白照旧：不论是否连接都持续运行，加白请求始终从真实出口发出。

## 相对 8.3.0

- Android 开关补齐松手后 200 毫秒的抬起保持，颜色与形变按原始行程变化；拖动中途接手动画时保留当前滑块位置。
- 修正开关和连接按钮的回弹曲线、连接按钮的反向缓动，以及动画中途反向时多等一个完整周期的问题。
- 弹出层退出时停止接收输入，避免快速连点重复执行旧菜单动作或关闭刚打开的表单；拖动关闭后立即打开新表单不再继承旧偏移。
- 对照官方安装版采集逐帧数据和录屏，增加快速反向、连续开关和弹出层交替的回归检查。

## 8.3.0 的补充修复

- 修复 macOS 首次从菜单栏打开订阅、加白等页面时可能停留在首页的问题。现在等前端导航监听器就绪，再处理最新的跳转请求。
- macOS 安装包检查逐项确认八个页面实际显示成功，脚本异常直接使检查失败，避免把首页误记为其他页面的截图。
