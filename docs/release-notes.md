po0-clash v6.2.0：统一 po0 / ggy 加白入口，新增类型选择与总开关，并更新扁平化图标。

## 本次更新

- po0 与 ggy 合并为一个「加白」页面和一个自动加白总开关，首页与侧栏统一显示加白状态
- 添加 token 时可选择 po0 token 或 ggy 完整加白链接，混合列表按类型管理，支持备注、编辑和删除
- 「立即加白」执行所有已配置条目；「查询 po0 状态」只查询 po0，不触发 ggy 写入
- po0 保留可调检查间隔，ggy 仍固定每 11 秒执行一次
- 修复快速切换总开关与页面退出期间的异步处理，避免读取已销毁的状态或重复重载路由
- 修复编辑期间配置恢复后可能保存重复凭据的问题；修改或清空备注时，结果卡片立即更新
- 更换为纯色、单主体的 P / 斜杠零图标，并同步 Android、macOS、Windows、主题图标、托盘与启动背景

## 升级说明

- 从 6.1.1 或更早版本直接覆盖安装即可，已有设置、po0 token、ggy 链接、备注与 po0 检查间隔全部保留
- 旧 po0 / ggy 开关任意一个开启，升级后总开关就开启，两种服务都会执行已配置条目；旧开关都关闭时，总开关保持关闭
- 没有配置条目的类型不发请求；总开关关闭后保存并重启，不会因旧 ggy 开关再次开启

## 安装

- Windows：po0-clash-6.2.0-windows-amd64-setup.exe（安装包）或 .zip（免安装）
- macOS：curl -fsSL https://raw.githubusercontent.com/yuuuki-creation/po0-clash/main/scripts/install-macos.sh | bash
- Android：po0-clash-6.2.0-android-arm64-v8a.apk（主流机型），可与官方 FlClash 共存

## 已知限制

- ggy 加白链接每次请求都会写入；日志里持续出现 evicted 说明白名单在被反复挤占
- Android 从最近任务划掉 po0-clash 后停止检查，重新打开应用即恢复
- 同时在用的网段超过白名单容量（po0 为 5 条，服务端已有的固定记录也占名额）时，各设备会互相挤占
- 与其他代理客户端同时开启系统代理或 TUN 会互相抢占，请只在一个应用里开启
- macOS 版本未经 Apple 公证，安装脚本会移除隔离属性；每次更新后首次开启虚拟网卡需重新输入管理员密码
