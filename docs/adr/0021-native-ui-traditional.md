# 0021. 原生版界面改为传统的平台风格，暖灰配色

- 状态：已采纳，7.1.0 起实现
- 日期：2026-11-01

## 背景

维护者认为现有的原生版界面不好看，要求重新设计，并逐个比较了 HTML 设计稿：

- 大色块加超大数字的方案太花哨，要求按传统的来。
- 灰白底配品牌绿显得苍白，冷灰和绿色相冲；Android 的绿色调配色又太绿。
- 三套配色对比后选了暖灰。

## 决定

- 三端都用传统的平台风格：系统字体、标准控件、普通列表和表格。不再模仿液态玻璃，Android 不再仿 iOS 26，改用 Material 3 的版式。
- 不放说明、提示和副标题这类小字。
- 配色用暖灰底、接近纯白的卡片和低饱和绿，绿色只给小控件和主操作。默认强调色是 `#24694C`，深色是 `#80CEA8`。
- 圆角、分界线、窗口拉伸时的布局和每个操作的动画按平台分别确定。
- 连接按钮放在页面顶部的状态行，三端一致，不再用浮动的启动按钮。
- 节点组多时，桌面用可滚动的组列表，窄窗口用下拉框；Android 手机用两级列表，宽屏左右并排。

具体数值和可操作的设计稿见 [design/native-ui](../design/native-ui/README.md)。

## 后果

- 取代 ADR 0019 的样式部分（液态玻璃、悬浮标签栏、浮动启动按钮和可展开的策略组卡片）。每端都有主界面和导航顺序这些决定不变。
- 修改 ADR 0020：默认强调色从系统蓝改为上面的绿色。主题色仍然可换，功能范围不变。
- [native-design.md](../development/native-design.md) 在三端改完前继续描述现有代码，之后由设计稿取代。
- 三端的界面代码都要改，顺序另定。设计稿列出的待定项，移植前由维护者决定。
