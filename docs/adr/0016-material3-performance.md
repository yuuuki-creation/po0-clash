# 0016. 简洁界面与按需统计刷新

- 状态：已采纳，仅适用于 Flutter 版（见 [0018](0018-native-rewrite.md)）
- 日期：2026-10-23
- 取代：[0010](0010-liquid-glass.md) 的视觉风格，以及 [0009](0009-frosted-glass-ui.md) 中悬浮导航与桌面控制侧栏的布局

## 背景

维护者要求降低整体性能消耗，并采用苹果官网式的简洁视觉：留白、清晰字体、克制配色与突出的主操作，同时检查 Flutter 与原生后端。
玻璃表面包含背景模糊、饱和度滤镜、渐变描边与软阴影；UI 统计在不可见时仍每秒请求 Core。
原生 IPC 写线程每 20 毫秒检查一次空队列，Go 的接收帧也逐条重新申请缓冲区。

## 决定

- 各平台共用 Material 组件与 ColorScheme 角色；表面固定为中性黑白灰，默认使用蓝色主操作。连接状态使用大字，信息卡片用留白分组，避免满屏描边。使用不透明表面，移除背景模糊和装饰性高光。
  保留主题色、深色和纯黑选项；兼容现有调用的 `Glass*` 内部名字不再代表玻璃效果。
- 手机和窄窗使用底部 NavigationBar，中等宽度使用紧凑图标导航，宽窗使用文字侧栏。
  桌面也有独立首页；连接、出站模式、配置和统计集中在首页，侧栏只负责导航。
- UI 的运行时长与流量采样只在 Core 已连接且主页可见时运行。macOS 显式开启托盘网速是例外。恢复可见时立即读取最新累计值，
  运行时长继续由原始开始时间计算；清理中断采样前的图表，避免把间断数据画成连续采样。
- `UiVisible` 只表示显示需求，不决定代理、TUN、系统代理或服务的运行状态。隐藏界面时，动画和页面轮询也暂停。
- 重新聚焦不会打断已有白名单定时器或重复排队；po0 配置间隔、ggy 固定 11 秒、网络变化立即处理和手动操作保留。
- Rust 写线程阻塞等待消息或关闭信号；停止连接时先标记停止，再唤醒写线程，最后 join。接收端预留事件类型字节，
  直接把完整事件移交 Dart，省去包装事件时的整帧复制。
- Go 每个连接复用接收缓冲区，最多保留 256 KiB；大帧临时分配，64 MiB 协议上限不变。
  `json.RawMessage` 在复用前完成参数复制，异步处理程序不持有会被覆盖的接收内存。
- 节点分组规范化保留未变化的不可变对象；只有携带运行时选择值的节点才复制。

## 验证边界

使用 provider、widget、Rust 队列/分帧测试与 Go 竞态检测验证生命周期、协议和显示行为。IPC 微基准只衡量接收帧环节，
不能当作整款应用的 CPU、内存或耗电下降比例。界面预览使用演示数据；实际设备仍需 release/profile 模式测量。
