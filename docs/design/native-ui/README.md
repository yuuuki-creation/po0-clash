# 原生版界面重设计

决定见 [ADR 0021](../../adr/0021-native-ui-traditional.md)。三端从 7.1.0 起按本页实现，本页取代 [native-design.md](../../development/native-design.md)。

## 原则

- 传统、贴近各平台：系统字体、标准控件、普通列表和表格。不用玻璃、渐变、大色块和超大数字。
- 不放说明、提示和副标题这类小字。每行只有名称和值。正文不小于 14，只有 Android 导航标签是 13。
- 三端共用配色和信息结构，形状、分界线和动画各按平台习惯。

## 配色

选定的是 B 暖灰：灰底带一点暖色，卡片接近纯白，绿色只给小控件和主操作。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面 | `#EFECE8` | `#181714` |
| macOS 侧边栏 | `#E5E3DE` | `#201F1C` |
| 卡片 | `#FEFDFC` | `#252421` |
| 卡片悬停 | `#F7F7F5` | `#2D2B28` |
| 控件轨道 | `#E2DFDA` | `#32302D` |
| 中性选中 | `#DEDCD7` | `#3E3D3A` |
| 斑马纹 | `#F7F5F0` | `#2B2A27` |
| 主文字 | `#211F1C` | `#F3F1EE` |
| 次要文字 | `#575551` | `#B9B7B3` |
| 弱化文字 | `#888681` | `#888682` |
| 强调色 | `#24694C` | `#80CEA8` |
| 强调色上的文字 | `#FFFFFF` | `#0D1F16` |
| 警告 | `#875800` | `#EBC573` |
| 错误 | `#AF2B25` | `#FB9890` |

对比度由 `demo/tools/palette.py` 按 WCAG 公式计算：正文对卡片 16.2:1（深色 13.8:1），次要文字对卡片 7.3:1（深色 7.8:1），
强调色上的文字 6.6:1（深色 9.2:1），都高于 4.5:1。

`palette.py` 里还留着没选中的 A 松灰和 C 深松，只作对比记录。macOS 侧边栏的选中项用实心强调色，这是维护者确认保留的。

## 圆角

单位是 px。

| 组件 | Windows | macOS | Android |
|---|---|---|---|
| 设置行、分组 | 4 | 10 | 外 16，内 4 |
| 按钮 | 4 | 6 | 全圆 |
| 分段控件 | 4 | 7 | 全圆 |
| 导航选中项 | 4 | 8 | 全圆 |
| 菜单 | 8 | 8 | 4 |
| 对话框 | 8 | 12 | 28 |
| 悬浮按钮 | 无 | 无 | 16 |

## 分界线

| 平台 | 设置行 | 表格 |
|---|---|---|
| Windows | 不画线，靠 4 px 间隙和背景色 | 只有表头下一条线，悬停和选中靠底色 |
| macOS | 1 px 细线，从文字起点开始 | 不画线，用斑马纹 |
| Android | 不画线，靠 2 px 缝隙和背景色 | 同设置行 |

选中项的标记也按平台：Windows 是底色加左侧指示条，macOS 是对勾，Android 是单选按钮。

## 窗口拉伸

| 平台 | 导航 | 内容 |
|---|---|---|
| Windows，最小 720×560 | 不小于 1008 显示完整侧栏；更窄时变图标栏，汉堡按钮展开覆盖层 | 放不下两列时变单列 |
| macOS，最小 620×480（暂定） | 不小于 760 显示侧边栏；更窄时收起，工具栏按钮展开覆盖层 | 同上 |
| Android | 小于 600 用底部导航；不小于 600 用侧边导航栏 | 不小于 840 时列表变两列 |

- 桌面端内容区不足 700 时：节点组列表换成下拉框，表格依次隐藏类型、规则、Token 和到期列。
- 窗口很大时：仪表盘、配置、加白和工具最宽 1100，代理和活动铺满。

## 动画

单位是 ms，“开 / 关”表示打开和关闭。

| 操作 | Windows | macOS | Android |
|---|---|---|---|
| 切换页面 | 上滑淡入 250 | 无 | 淡入微缩放 300 |
| 导航选中 | 指示条滑动 250 | 无 | 指示器展开 300 |
| 分段控件 | 滑块 167 | 滑块 200 | 底色加对勾 150 |
| 开关 | 167 | 200 | 200 |
| 选节点 | 指示条长出 167 | 无 | 单选点放大 150 |
| 菜单开 / 关 | 167 / 83 | 无 / 120 | 150 / 100 |
| 对话框开 / 关 | 250 / 83 | 200 / 150 | 300 / 150 |
| 进二级页 | 缩放 250 | 淡入 120 | 横移 300 |

- 三端相同：删除行收起 200，添加行展开 250，换主题淡变 200，速度图每秒匀速滚动，连接状态点变色 200。
- Android 另有：点按水波纹，底部面板 400 / 200，节点组进出二级页横移 300。
- 不做动画：搜索过滤和实时数字更新，要跟得上输入和数据。
- 跟随系统的“减少动态效果”；“页面切换动画”设置只影响切页。

## 连接按钮

三端都放在页面顶部的状态行，右侧按钮：已连接是次要样式的“断开连接”，未连接是强调色的“连接”，连接中禁用并显示转圈。
按钮宽度固定，切换时不跳动。Android 不再用悬浮的启动按钮，悬浮按钮只留给配置和加白页的“添加”。

## 节点组

按 24 个组、每组最多 20 项验证。

| 场景 | 选组 | 选节点 |
|---|---|---|
| 桌面宽窗口 | 左侧列表独立滚动，每行是组名和当前节点 | 右侧表格 |
| 桌面窄窗口 | 下拉框，展开后滚到当前组 | 下方表格 |
| Android 手机 | 第一级列表：组名、当前节点、延迟 | 第二级列表，有返回 |
| Android 不小于 840 | 左侧列表 | 右侧列表 |

- 一个搜索框同时匹配组名和节点：组名命中时显示该组全部节点，否则只显示命中的节点，与现有应用一致。
- 排序：默认、按延迟、按名称。定位：跳回主组和正在用的节点。
- `selectable` 为假的组（URLTest、Fallback 等）只显示当前节点，不能手动选。
- Android 第一级的测速按钮测全部节点，第二级测当前组；桌面只测当前组。

## 待定

移植前要决定保留还是去掉，去掉需要维护者同意（ADR 0020）：

- 组图标：内核有 `icon` 字段，组多时有助于辨认，demo 没有放。
- 布局切换（标签 / 列表）、节点密度、图标样式和节点卡片样式这些视图设置。
- 桌面端的“测试全部”。
- 直连模式下代理页的空状态。
- 主题色：demo 只有默认绿；ADR 0020 要求可换，换色时的深色配对值还没定。

几百个节点时可能要用虚拟列表，demo 证明不了这一点。

## demo

`demo/` 是可操作的设计稿，数据都是示例。修改 `src/` 后运行：

```bash
python docs/design/native-ui/demo/tools/palette.py
```

```bash
python docs/design/native-ui/demo/tools/build.py
```

产物在 `demo/build/project/`，不入库。`*.dc.html` 由 Claude 设计画布的运行时渲染，运行时不是本仓库的代码，也不入库；本地预览要
把它放到同目录的 `support.js`，再用静态服务器打开。`tools/shot.mjs` 用无头 Chrome 操作页面并截图，`tools/sheet_page.py` 把截图拼成总览。
