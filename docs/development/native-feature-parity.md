# 原生版功能对齐 FlClash

决定见 [ADR 0020](../adr/0020-native-feature-parity.md)：Flutter 版（FlClash 加本 fork）有的功能，原生版全都要有，没有例外。
本页是逐项清单和实施顺序。「状态」写所有适用的平台是否都已做完：「已有」是内核和这些平台都接上了，「内核已有」是内核已就绪、
界面还没做齐，「部分」是内核也缺或功能只做了一部分；「内核」「界面」两列写还缺什么。

状态按 native-v7.1.1 的代码核对（2026-11-02），只说明功能接上了，不说明测试过。验证情况见
[native-progress.md](native-progress.md)。

## 导航

与 Flutter 版一致：仪表盘、代理、配置（订阅）、加白、活动（请求 / 连接 / 日志）、工具。桌面端「活动」在侧边栏里；手机上标签栏
只放仪表盘、代理、配置、加白、工具五项，「活动」从工具页进入。关掉「日志捕获」时不显示日志入口；没有配置时代理页提示先添加。

## 顺序

1. 内核：设置模型覆盖上表全部配置项和应用设置（备份恢复要带上）；内网 IP、IP 质量；节点改名删除；覆写（规则先做，JS 脚本
   最后）；备份与恢复；资源自动更新；启动记录。三端的 UniFFI / Tauri 接口一起加。
2. 三端界面按导航逐页补齐，先活动页和工具页的配置表单，再代理页布局与 providers、配置编辑，最后覆写、备份、快捷键、外观等。
3. 每一项在所有适用的平台都做完才算完成，在本页把状态改成「已有」。
